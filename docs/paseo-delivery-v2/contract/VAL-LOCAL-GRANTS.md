# VAL-LOCAL-GRANTS: Independent exact-draft publication policies

Surface: cli/HTTP.
Needs: Owner-controlled foreground policy and queued drafts.
Behavior: PR and issue modes independently off/explicit/automatic defaultoff; explicit publish binds repoID/actor/kind/exact content digest/revision, policy/content drift invalidates grant; automatic needs trusted optin; UI/task data cannot elevate mode or approve a different draft.
Evidence: All mode combinations and stale/forged grant refusals plus one authorized positive publish for each kind.
